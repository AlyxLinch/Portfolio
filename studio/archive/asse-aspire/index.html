ASSE Aspire Website

A mobile-first site for international participants in Summer Work Travel and Intern/Trainee programs. I was the sole designer and developer from concept to completion.

Overview

Participant information needed to feel clear fast.

The site had to serve an international audience looking for program information, resources, and trust signals on a wide range of devices. I shaped the UX, visual layout, copy structure, and front-end build around mobile access first.

Features

Responsive without feeling generic.

  • Mobile optimization and dynamic font sizing.
  • Accessible font choices and clearer hierarchy.
  • Bootstrap 5.0 components customized into a branded layout.
  • CSS animations used as gentle orientation cues.

Navigation flow

Information architecture before decoration.

HomeResourcesAboutContactParticipant support

Challenges

Mobile, access, and trust.

The hardest parts were designing mobile-first, securing participant photo permissions, and keeping the experience accessible while still giving the organization a warm, welcoming identity.

Outcome

A responsive launch with a clearer participant path.

The final site launched with a fully responsive layout, a more intuitive structure for mobile visitors, and a visual system that made the program feel more organized and approachable.
